# Kolay

Kolay (Türkçe programlama dili) için VS Code eklentisi.

- Renklendirme: anahtar kelimeler (tr ve us yazımı), tipler, hazır fonksiyon ve metotlar,
  f-yazılar, onaltılık sayılar (`0xFF`), `#Güvensiz` ve `dış kütüphane`.
- Hazır kod parçaları: `ata`, `fonksiyon`, `eğer`, `kere`, `her`, `sürece`, `tür`, `arayüz`,
  `seçenek`, `eşleştir`, `olarak`, `veya`, `dış`, `dışa`, `kütüphanesindeki` ve diğerleri.
